
# Luz da Lua Aromas — Frontend V8

Esta versão mantém o visual aprovado e corrige o fluxo da loja.

## O que o cliente consegue fazer

- entrar na conta;
- criar conta;
- sair;
- salvar o carrinho por conta;
- recuperar o carrinho depois de entrar novamente;
- navegar pelo catálogo;
- escolher aroma e quantidade;
- adicionar ao carrinho;
- revisar o pedido;
- escolher Pix, cartão ou dinheiro como informação do pedido;
- enviar tudo diretamente para o WhatsApp da Luz da Lua;
- receber uma mensagem organizada com os dados do pedido;
- consultar o histórico de pedidos no navegador.

A autenticação e o carrinho desta versão frontend funcionam localmente com localStorage. O backend anterior não foi apagado nem alterado. Quando você quiser conectar as duas partes, trocamos as funções locais por chamadas `/api/...`.
